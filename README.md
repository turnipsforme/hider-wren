# Tab Bar Hider

An Obsidian desktop plugin that toggles the tab bar while preserving its height as a draggable hidden header.

## Install with BRAT

1. Install the BRAT plugin in Obsidian.
2. Add `turnipsforme/hider-wren` as a beta plugin.
3. Enable **Tab Bar Hider** in **Settings > Community plugins**.

## Usage

Use the **Toggle tab bar** command from Obsidian's command palette.

## Development

Install dependencies and build the production bundle:

```sh
npm install
npm run build
```
